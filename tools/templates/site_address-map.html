Mapped apertures and register definitions are not RTL test coverage. Memory-model backing may be far smaller than the declared DDR/HBM windows. Unassigned holes are not backed storage; read/write evidence belongs to each run's passive AXI trace.

The default chip uses modeled AXI RAM; native LiteDRAM controller CSRs are selectable only from source-verified DDR test variants. PCIe requester and endpoint DBI definitions are always available as source-only references; the separate host PCIe Type-0 configuration space is not SoC MMIO.

DDR4 device mode register definitions · MR0–MR6

DDR4 MR0–MR6 are programmed via DFI MRS commands, not CPU-addressable MMIO. This page displays source-defined fields only. Actual programmed values, decoded DFI cycles, after-init changes, scoreboard checks and source evidence belong exclusively to the individual Test Runs and their per-test reports.
