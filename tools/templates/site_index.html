Interpret source, models and execution evidence

The architecture diagram represents generated structural connectivity. It does not prove the connected optional datapaths ran together. Default DDR/HBM windows use AXI models; controller, PCIe host and Ethernet configurations are variant-specific. Verified execution steps and observed AXI/TLP/GMII/DFI events are published per test, not inferred from the diagram.
