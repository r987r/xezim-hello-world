Timing semantics: router counts are structural, not clock-cycle delays. Where a clean controlled one-beat trace matches this site's source SHA, the measured AXI boundary deltas break down request/response time per mesh and terminal AXI service. Router-internal hop cycles and isolated DDR/HBM device latency are not measured. The real PULP iDMA engines are connected in the default generated RTL and exercised in chip-dma mode; chip-cpu-dma verifies CPU-programmed transfers. The default generated chip retains behavioral AXI RAM for DDR/HBM; the separate opt-in chip-ddr4-real full-chip variant instantiates genuine pinned LiteDRAM controller RTL and captures read-only DFI/behavioral BankModel commands (merged #117). Do not infer that Ethernet, PCIe host, and real LiteDRAM are all live in one variant or that DFI activity proves a physical PHY.
